# 腦力探險家 (Brain Explorer) — 專案規格文件

## 1. 專案背景與設計哲學

### 1.1 起源問題
線上 IQ 測驗(如 Mensa 挪威站 https://test.mensa.no/)只給分數,不給解析。對孩子而言,做完只是「被評分」,沒有「學到怎麼想」。本專案要把智力測驗從**鑑別工具**轉為**學習素材**。

### 1.2 核心原則

| 原則 | 具體做法 |
|------|---------|
| **不抄題、用題型** | 不複製 Mensa 等有版權的題目;但 Raven's Matrices 等「題型結構」是公開的認知科學知識,可自由運用 |
| **引導式解析** | 答錯時先給「引導式提問」(讓孩子自己想),再給完整解析。不是直接給答案 |
| **能力標籤** | 每題標註訓練的認知能力(如「雙向規律推理」「空間旋轉」),讓孩子知道自己練到什麼 |
| **正向回饋** | 答錯不用「✗ 答錯了」,用「沒關係,我們一起想想!💪」;答對標綠色 + 慶祝動畫 |
| **視覺化呈現** | 圖形題、空間題用 SVG 真的畫出來,降低閱讀負擔 |
| **難度梯度** | 同題型分入門 / 中階 / 挑戰三檔,讓孩子能階梯式進步 |

### 1.3 目標使用者
- **主使用者**:國小 1-6 年級孩童
- **設計重點**:文字精簡(低年級耐心有限)、視覺直觀、難度可選

## 2. 現有原型概覽

### 2.1 檔案結構
**單一 HTML 檔**:`iq_brain_explorer.html` — 包含所有 CSS、JS、題庫。

### 2.2 技術棧
- 純 HTML / CSS / JS,**不需要任何 build tool**
- Google Fonts: `Fredoka` (顯示用) + `Noto Sans TC` (中文)
- 純 SVG 繪圖,**不使用外部圖片**
- **不使用 localStorage / sessionStorage**(若要存進度,用 in-memory state)

### 2.3 主要流程
```
首頁 (menuScreen)
  ↓ 點某題型某難度
答題頁 (quizScreen) → 答完所有題 →
  ↓
結算頁 (finalScreen) → [重玩這關] or [回主選單]
```

### 2.4 現有題目數量
- 6 題型 × 3 難度 × 2 題 = **36 題**
- **本規格目標:擴展到每難度 5-8 題,總計 90-144 題**

## 3. 六大題型詳細規格

### 3.1 矩陣推理 (matrix) 🎯

**Mensa 主力題型,Raven's Progressive Matrices 結構。**

#### 題型結構
- 2×2 或 3×3 格子,其中一格是「?」
- 從橫向、直向、或其他關係找出規律

#### 子類型(可作為擴充方向)
| 子類型 | 範例 | 難度 |
|-------|------|-----|
| 單變數(每排相同) | 每排都是同形狀 | 入門 |
| 雙向變化(形狀×顏色) | 橫變形狀、直變顏色 | 入門/中階 |
| 三變數(形狀×顏色×數量) | 三項獨立規律 | 中階 |
| 拉丁方陣 | 每排每列每種屬性各出現一次 | 中階/挑戰 |
| 算術運算(相加/相減) | 前兩格相加 = 第三格 | 挑戰 |
| 旋轉規律 | 每格圖形旋轉一定角度 | 挑戰 |

#### 引導語設計原則
- **不劇透**規律類型,只說「橫向看一下」「兩個方向都有規律」
- 例外:極難題可以給多一點提示,如「這題不只是橫直,試試對角線」

---

### 3.2 圖形序列 (sequence) 🔄

**一排圖形,找下一個。**

#### 子類型
| 子類型 | 範例 | 難度 |
|-------|------|-----|
| ABAB 循環 | 圓方圓方→? | 入門 |
| ABC 三項循環 | 粉綠黃粉綠→? | 入門 |
| 等角度旋轉 | 箭頭每次轉 45° | 入門/中階 |
| 巢狀元素 | 外框+內部各自變化 | 中階 |
| 不同步變化 | 形狀每格變,顏色每兩格變 | 挑戰 |
| 分組規律 | 兩兩一組,組內顏色相同 | 挑戰 |
| 累積增加 | 每格多一個元素 | 中階 |

---

### 3.3 空間能力 (spatial) 🧊

**純空間想像,Mensa 也常考。對國小孩子偏難,但可以練出來。**

#### 子類型
| 子類型 | 範例 | 難度 |
|-------|------|-----|
| 折紙打洞展開 | 對摺一次後打洞,展開有幾個洞 | 入門 |
| 立方體方塊計數 | 堆疊圖,問共幾塊(含被擋住的) | 入門/中階 |
| 多次對摺 | 摺兩次後展開 | 中階 |
| 立方體展開圖 | 哪兩個面相對 | 中階 |
| 展開圖判斷 | 哪個展開圖能折成立方體 / 哪個不行 | 挑戰 |
| 立體乘法 | 4×4×4 缺幾塊才能堆滿 | 挑戰 |
| 鏡像 | 圖形的鏡像是哪個 | 中階 |

#### 視覺呈現重點
- 立方體用 **isometric SVG**(可參考現有範本)
- 折紙題用「平面+虛線」表示對摺位置
- 必要時用「📄 → 對摺 → ✂️ → ?」這種視覺流程圖

---

### 3.4 進階數列 (numseries) 🔢

**數字裡的規律。從等差到費氏。**

#### 子類型
| 子類型 | 範例 | 難度 |
|-------|------|-----|
| 等差數列 | 2,4,6,8,? | 入門 |
| 等比數列 | 2,4,8,16,? | 入門/中階 |
| 平方數 | 1,4,9,16,? | 入門 |
| 二階等差(差的差) | 2,3,5,8,12,? (差為 1,2,3,4) | 中階 |
| 交錯數列(雙串) | 2,10,4,20,6,? | 中階 |
| 費氏數列 | 1,1,2,3,5,8,? | 挑戰 |
| 階乘規律 | 1,2,6,24,? | 挑戰 |
| 混合運算 | 每次 ×2 再 +1 | 挑戰 |

---

### 3.5 類比推理 (analogy) 🔗

**A 之於 B,如同 C 之於 ?**

#### 子類型
| 子類型 | 範例 | 難度 |
|-------|------|-----|
| 功能類比 | 鳥:翅膀 :: 魚:鰭 | 入門 |
| 反義詞 | 熱:冷 :: 高:矮 | 入門 |
| 工作場所 | 廚師:廚房 :: 醫生:醫院 | 入門/中階 |
| 聲音 / 食物 | 狗:汪 :: 貓:喵 | 入門 |
| 原料追溯 | 紙:樹 :: 麵包:小麥 | 挑戰 |
| 部分與整體 | 手指:手 :: 花瓣:花 | 中階 |
| 因果關係 | 火:煙 :: 雨:? | 中階 |
| 程度副詞 | 笑:大笑 :: 看:盯 | 挑戰 |

#### 注意事項
- **避開需要文化背景**的題目(如成語、典故)
- 干擾選項要設計得有理由(例如該題考「地點」,干擾選項是「工具」「對象」)

---

### 3.6 多元素變化矩陣 (multivar) 🌈

**矩陣推理的進階版,多個變數同時運作。**

#### 子類型
| 子類型 | 範例 | 難度 |
|-------|------|-----|
| 2×2 雙變數 | 橫變顏色、直變形狀 | 入門 |
| 3×3 三變數獨立 | 形狀+顏色+數量同時變 | 中階 |
| 拉丁方陣 | 每排每列三種屬性各 1 個 | 中階 |
| 四變數 | 形狀+顏色+大小+點數 | 挑戰 |
| 位置交換 | A左B右 → B左A右 → 還原 | 挑戰 |
| 屬性繼承 | 兩格特徵在第三格組合 | 挑戰 |

## 4. 難度梯度定義

### 4.1 三檔標準

| 難度 | 標籤 | 顏色 | 認知負擔 |
|-----|-----|-----|---------|
| 入門 | ⭐ Easy | 綠色 `#E8F8E0` | 單一規律、一個變數 |
| 中階 | ⭐⭐ Mid | 黃色 `#FFF3D6` | 兩個變數同步、或單變數但較複雜 |
| 挑戰 | ⭐⭐⭐ Hard | 紅色 `#FFE0E8` | 三個以上變數、需多步推理、有干擾 |

### 4.2 各題型難度錨點(以矩陣為例)

```
入門:每排三格內容完全相同(只考「找到一致性」)
中階:橫變形狀、直變顏色(雙向獨立規律)
挑戰:三變數 + 規律是「相加」「輪換」等非直觀
```

### 4.3 跨年級對應參考

| 難度 | 大致對應年級 |
|-----|-------------|
| 入門 | 1-2 年級可獨力完成,3-6 年級暖身 |
| 中階 | 3-4 年級主力,5-6 年級可解,1-2 年級需要陪同 |
| 挑戰 | 5-6 年級可挑戰,中學以下偏難,有助於資優生練思考 |

## 5. 題目資料結構

### 5.1 完整 schema

```javascript
{
  prompt: string,        // 題目敘述(引導語,不劇透規律類型)
  visual: string,        // HTML 字串,通常是 SVG / div 組合
  options: [
    { text: string, html?: string }  // text 必填,html 可選(顯示圖形)
  ],
  answer: number,        // 正確答案 index (0-based)
  hint: string,          // 答錯時的「引導式提問」(讓孩子自己想)
  explanation: string,   // 完整解析(可含 <strong> 標籤)
  skill: string          // 訓練的認知能力標籤(短句)
}
```

### 5.2 範例(矩陣推理入門)

```javascript
{
  prompt: '橫向看一下,每一排有什麼規律?',
  visual: `<div class="matrix-3x3">
    ${mc(svg(circle(COLORS.pink, 14)))}
    ${mc(svg(circle(COLORS.pink, 14)))}
    ${mc(svg(circle(COLORS.pink, 14)))}
    ${mc(svg(square(COLORS.teal)))}
    ${mc(svg(square(COLORS.teal)))}
    ${mc(svg(square(COLORS.teal)))}
    ${mc(svg(triangle(COLORS.yellow)))}
    ${mc(svg(triangle(COLORS.yellow)))}
    ${mc('', true)}
  </div>`,
  options: [
    { html: svg(circle(COLORS.pink, 14)), text: '粉紅圓' },
    { html: svg(triangle(COLORS.yellow)), text: '黃三角' },
    { html: svg(square(COLORS.teal)), text: '藍綠方' },
    { html: svg(star(COLORS.pink)), text: '粉紅星' }
  ],
  answer: 1,
  hint: '看橫的:第一排都是粉紅圓、第二排都是藍綠方,第三排前兩個是什麼?',
  explanation: '每一排的三格是<strong>同樣的東西</strong>。第三排前兩格是黃色三角形,所以第三格也要是<strong>黃色三角形</strong>。',
  skill: '橫向規律識別'
}
```

## 6. UI / UX 設計規範

### 6.1 設計語言
**Playful / Toy-like**,但不能幼稚到讓中高年級孩子嫌幼稚。
- 圓潤邊角(`border-radius: 12-28px`)
- **粗黑邊框**(`border: 3-4px solid #2D2A4A`)
- **離地陰影**(`box-shadow: 0 6px 0 rgba(45,42,74,0.15)`)— 模仿樂高/卡片實體感
- **動畫適度**(慶祝、震動、彈跳,但不要太頻繁)

### 6.2 配色系統(已定義 CSS 變數)

```css
--bg: #FFF8E7          /* 米黃背景 */
--bg-paper: #FFFFFF    /* 卡片底 */
--ink: #2D2A4A         /* 深紫黑 — 主文字、邊框 */
--ink-soft: #6B6890    /* 副文字 */
--primary: #FF6B9D     /* 粉紅 — 主按鈕、強調 */
--secondary: #4ECDC4   /* 藍綠 — 標籤、輔助 */
--accent: #FFD93D      /* 黃 — 「?」格、高亮 */
--purple: #9B7EDE      /* 紫 — 難度星星 */
--orange: #FF9F45      /* 橘 */
--success: #6BCB77     /* 答對綠 */
--error: #FF8C8C       /* 答錯紅 */
```

### 6.3 字型
- 顯示用:`Fredoka` (圓潤、童趣)
- 中文:`Noto Sans TC` weight 500/700/900

### 6.4 三個主要畫面

#### A. 首頁(menuScreen)
- 標題 + 六張題型卡片(grid 排版,RWD 自動換行)
- 每張卡片顯示:emoji + 題型名 + 簡短描述 + 三顆星難度按鈕

#### B. 答題頁(quizScreen)
- 上方:回主選單按鈕 + 進度條 + 進度文字(例:「矩陣推理 · ⭐ 入門 · 第 1 題 / 共 5 題」)
- 中間:卡片(左上角題型 badge、右上角難度 badge、題目文字、視覺、選項)
- 答完後:回饋區(對/錯標頭 + hint + 解析 + 技能標籤)+ 下一題按鈕

#### C. 結算頁(finalScreen)
- 🏆 動畫 + 評語(依答對率)
- 三格統計(答對 / 總題數 / 正確率)
- [重玩這關] / [回主選單] 按鈕

### 6.5 互動細節
- 選項按下後:對的變綠色 + pop 動畫 + 全螢幕飄出 🎉;錯的變紅色 + shake
- 答錯時:**正確答案也標綠**,讓孩子看到對的長什麼樣
- 慶祝 emoji 隨機:`['🎉', '⭐', '🌟', '✨', '🎊']`

## 7. SVG Helper 函數庫

**所有圖形題透過 helper 函數產生,確保視覺一致。**

### 7.1 已有的 helpers

```javascript
// 包裝 SVG 容器
svg(content, size = 50)

// 基本形狀(都接受顏色參數)
circle(c, r=16, cx=25, cy=25, stroke='#2D2A4A')
square(c, side=28, x=11, y=11)
triangle(c)
star(c)
diamond(c)
hex(c)

// 箭頭(deg 為旋轉角度)
arrow(deg, c='#FF6B9D')

// 點點(1-6 個,擺放在固定位置)
dots(n)

// 多個相同形狀疊放(1/2/3/4 個)
multiShape(shape, n, c)

// 矩陣格子
mc(content, isUnknown = false)
```

### 7.2 顏色常數

```javascript
const COLORS = {
  pink: '#FF6B9D', teal: '#4ECDC4', yellow: '#FFD93D',
  purple: '#9B7EDE', orange: '#FF9F45', blue: '#5B9DEC',
  white: '#FFFFFF'
};
```

### 7.3 擴展時可增加的 helpers

> 寫新題時若發現某類視覺重複出現,封裝成 helper,不要直接寫一坨 SVG inline。

建議擴充:
- `cubeStack(layout)` — 接受 [[1,1,1],[0,1,0]] 這種陣列,自動畫 isometric 方塊堆
- `cubeNet(faces)` — 接受六個面的內容,畫立方體十字展開圖
- `foldedPaper(folds, holes)` — 畫折紙打洞示意圖
- `analogyRow(a, b, c, unknown)` — 標準類比版型

## 8. 擴展任務清單

### 🎯 Phase 1:題庫擴充(優先)

**目標**:每題型每難度從 2 題擴充到 **5-8 題**。

| 題型 | easy 目標 | mid 目標 | hard 目標 |
|-----|----------|---------|----------|
| matrix    | 6 題 | 6 題 | 5 題 |
| sequence  | 6 題 | 6 題 | 5 題 |
| spatial   | 5 題 | 5 題 | 4 題 |
| numseries | 6 題 | 6 題 | 5 題 |
| analogy   | 6 題 | 6 題 | 5 題 |
| multivar  | 5 題 | 5 題 | 5 題 |
| **合計**  | **34** | **34** | **29** |

**總目標題數:約 100 題。**

#### 出題注意事項
1. **每題答案唯一**:設計時推三次,確保沒有第二種合理解法
2. **干擾選項要設計**:不是隨便放,而是「常見的錯誤思路」會選的
3. **解析的引導句**:用孩子聽得懂的話,不要說「請推導橫向序列規律」這種學術話
4. **能力標籤(skill)**:短、具體、可累積。例如「橫向規律識別」「雙向規律推理」
5. **避免文化偏見**:不要出需要懂某地方言、典故、流行文化才能解的題

### 🛠️ Phase 2:功能增強

#### A. 隨機抽題模式
- 主選單加一個「隨機綜合測驗」按鈕,從各題型隨機抽 10 題
- 完成後給「能力雷達圖」(用 SVG 畫六邊形圖)

#### B. 錯題回顧
- 答錯的題目存進 `state.wrongList`
- 結算頁加「複習錯題」按鈕,只重做答錯的題

#### C. 學習進度
- 用 in-memory state 記錄這次 session 各題型答對率
- 主選單卡片角落顯示「上次正確率」徽章
- ⚠️ **不要用 localStorage**(會被 artifact 限制),只在 session 內生效

#### D. 動態出題提示
- 連續答錯 2 題 → 自動降一檔難度建議

## 10. 已知 bug 與避坑指南

### 10.1 已修復的歷史 bug

#### Bug #1:`dots()` 函數陣列稀疏問題
- **問題**:原本 `dots(n)` 用陣列 `positions[n]`,index 4 漏寫,當 `n=4` 時回傳 `undefined`,後續 `.map()` 爆炸
- **修法**:改用物件 `{1:[...], 2:[...], ...}`,並加 `if (!positions[n]) return ''` 防呆
- **教訓**:helper 函數要做邊界防呆

#### Bug #2:題目寫到一半邏輯錯誤
- **問題**:寫題寫到一半發現選項對不上答案,自己在 explanation 裡自言自語「等等⋯我們重看」,結果留在程式碼裡交付
- **修法**:寫完每題立刻自我驗證(三遍推導),不對就重來,不要留半成品
- **教訓**:**禁詞檢查**列在 9.2(等等/不對/我們重看/重看)

### 10.2 寫程式時的避坑

#### ⚠️ 一定要做的事
1. **本地用 jsdom 跑過** — 確認 QUESTIONS 物件能完整初始化、首頁能 render 出 6 張卡片
2. **每題寫完跑一次答案推導** — 別自己出的題自己都解不出來
3. **修 bug 之後跑禁詞檢查**:
   ```bash
   grep -nE "等等|不對!|我們重看|重看:" iq_brain_explorer.html
   ```

#### ⚠️ 一定不要做的事
1. **不要用 localStorage / sessionStorage** — artifact 環境會 fail
2. **不要外連任何 CDN(除了 Google Fonts)** — 確保離線也能打開
3. **不要在 visual 字串裡寫 `</script>`** — 會破壞外層 script 標籤
4. **不要用模板字串塞超過 200 行的 HTML** — 拆成 helper 函數
5. **不要依賴 DOM ready 事件以外的時序假設**(本檔不用 React,純 vanilla JS)

### 10.3 SVG 注意事項

- 所有形狀 `stroke="#2D2A4A"` 統一深紫黑邊框
- 邊框寬度 `stroke-width="2.5"` 統一
- 多形狀組合要用 `<g transform="...">` 包起來
- 旋轉用 `<g transform="rotate(deg cx cy)">`,**不要**用 CSS transform(SVG 內部會出怪事)
