## ✨ 特色

- **六大題型** × **三種難度**:矩陣、序列、空間、數列、類比、多元變化
- **不只給答案,還給「怎麼想」**:每題答錯都有引導式提問,讓孩子自己推理
- **個人能力雷達**:看自己在哪個領域強、哪個領域要加強(資料只留在你的瀏覽器,不外傳)
- **學習模式 / 測驗模式**:平常練習有提示,要正式評量就切換成測驗
- **完全免費、開源、無廣告、不收個資**

## 👨‍👩‍👧 給家長 / 老師

### 怎麼用?
1. 點上方連結,直接開始玩,**不用註冊、不用安裝**
2. 主選單選一個題型卡片(例如「矩陣推理」)
3. 選難度:⭐ 入門 / ⭐⭐ 中階 / ⭐⭐⭐ 挑戰
4. 答完一整關會看到能力雷達跟錯題回顧

### 適合年齡?
- **小一、小二**:從入門開始,需要陪同
- **小三、小四**:中階主力,挑戰需協助
- **小五、小六**:可挑戰所有難度
- 資優生 / 高年級可當思考訓練

### 資料隱私
- ✅ **完全不收集個人資料** — 沒有姓名、email、照片
- ✅ **資料只存在你的瀏覽器** — 換手機 / 清紀錄就消失,符合兒童資料最小化原則
- ✅ **沒有後端伺服器** — 純靜態網頁
- ✅ **沒有第三方追蹤** — 不裝 Google Analytics、不裝廣告 SDK

### 回饋
每一題的右下角有「💬 回饋這題」按鈕。覺得題目太難、答案有誤、或想到更好的解法,都歡迎按下去告訴我們,幫忙改進題庫品質。
